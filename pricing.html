What affects your price?

The starting scope is one trademark in one class. I’ll list the legal fee and applicable USPTO fees separately in your quote.

$350 per class in base USPTO filing fees for a standard U.S. application filed online.

See USPTO fee information
Additional trademarks or classes

Each application covers one trademark and can cover multiple classes of goods or services. Additional trademarks require separate applications, and each additional class adds to the filing cost.

Custom descriptions and surcharges

Using a free-form description instead of the USPTO’s standard descriptions adds $200 per affected class. Other surcharges can apply, including for unusually long custom descriptions or missing required information.

Filing before you start using your mark

An intent-to-use filing may be available if you have a bona fide intent to use the mark in U.S. commerce. You’ll submit evidence of use before registration. The USPTO charges $150 per class for the use filing and $125 per class for each extension request.

If the USPTO issues a Notice of Allowance, you have six months to file a Statement of Use or request an extension. See USPTO intent-to-use guidance.
