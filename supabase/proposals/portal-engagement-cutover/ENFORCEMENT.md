## Bounded model limits

The existing application has **one configured instance of each shared service per legal client** (for example, one website-monitor configuration). Each is explicitly bound to an engagement and matter. Giving a second engagement the same entitlement does NOT silently inherit the first engagement's configuration/history. Parallel service configurations for the same client, moving retained service history, and attorney setup/reassignment controls are not introduced here. A stale/closed configuration cannot be repurposed through normal client writes; reconfiguration needs a separately reviewed workflow. Portfolio/matter/evidence scopes can coexist across multiple engagements.

First-relationship invitation/acceptance UI and attorney engagement creation/activation screens remain separate work. This phase preserves the four existing approved fictional relationships and supplies a protected closure boundary; it does not invent acceptance for a new Member. The existing editable Brand Map proposal is not deployed in this Test schema; the installed map consumes marks and reviewed BCM publications and receives their scope filtering.

Already downloaded content cannot be withdrawn from a user's device. The storage check governs subsequent authenticated downloads; existing UI disposes displayed evidence when the page is hidden/signed out. No new signed public download links are created.
